## Los 5 Pilares de [AWS](https://aws.amazon.com/) Well-Architected Framework {id="los-5-pilares-de-aws-well-architected-framework"}

![AWS](/assets/blog/2ebe3cf8e7ae57e98d3af846b3dae0c78a497d5c6b20855b8918efd0886f0265.jpg)

El AWS Well-Architected Framework es CLAVE para los exámenes de AWS. Es el documento que define cómo construir sistemas en la nube que funcionen.

¿Por qué es TAN importante? Porque AWS basa muchas preguntas del examen en sus 5 pilares:

| Pilar | ¿Qué hace? | ¿Cómo lo hace? |
| --- | --- | --- |
| Excelencia Operativa | Ejecuta cargas de trabajo | • [Infraestructura como código](/blog/como-crear-infraestructura-como-codigo-en-aws-con-aws-cloudformation/)  • Cambios pequeños y fáciles de revertir |
| Seguridad | Protege datos y sistemas | • Seguridad en cada nivel  • Procesos automatizados |
| Fiabilidad | Mantiene todo funcionando | • Se recupera solo  • Prueba todo |
| Eficiencia del Rendimiento | Usa recursos con inteligencia | • Revisa la arquitectura  • Usa AWS al máximo |
| [Optimización de Costos](/blog/10-estrategias-de-optimizacion-de-costos-en-aws/) | Ahorra dinero | • Mide gastos  • No compra más de lo necesario |

Para aprobar el examen, necesitas:

1\. **Conocer cada pilar a fondo**

AWS pregunta cosas específicas como "¿Cómo proteges tus datos?" o "¿Cómo manejas los accesos?"

2\. **Entender casos reales**

No memorices - aprende a usar estos principios en situaciones reales.

3\. **Saber quién hace qué**

AWS y tú comparten responsabilidades de seguridad. Este tema sale MUCHO en el examen.

**Tip para el examen**: Abre la Consola de AWS y mira cómo funciona todo esto en la práctica. Te ayudará a responder mejor las preguntas del [AWS Certified Cloud Practitioner CLF-C02](/blog/guia-de-estudio-aws-certified-cloud-practitioner-clf-c02/).

## 2. Guía de Servicios AWS {id="2.-gu%C3%ADa-de-servicios-aws"}

AWS ofrece más de 200 [servicios en la nube](/blog/cloud-computing-en-espanol-fundamentos-basicos/). Para aprobar los exámenes, necesitas conocer los servicios básicos y cómo trabajan juntos.

| Categoría | Servicios Clave | ¿Qué hacen? |
| --- | --- | --- |
| Computación | EC2, Lambda | Ejecutan aplicaciones y código |
| Almacenamiento | S3, EBS | Guardan datos y archivos |
| Contenedores | ECS | Manejan apps en contenedores |
| [Bases de Datos](/blog/aws-bases-de-datos-introduccion-basica/) | RDS, DynamoDB | Almacenan datos estructurados |

**¿Qué busca el examen?**

El examen se enfoca en 3 áreas:

1\. **Conocimiento de servicios**

Los exámenes evalúan si sabes qué servicio usar y cuándo usarlo. Las preguntas suelen combinar varios servicios en un solo escenario.

2\. **Costos**

Cada servicio tiene su forma de cobrar. AWS QUIERE que sepas cómo ahorrar dinero y optimizar gastos.

3\. **Conexiones entre servicios**

No basta con conocer servicios individuales. Necesitas saber cómo funcionan juntos para crear soluciones completas.

**Los servicios que MÁS aparecen:**

| Servicio | Enfócate en |
| --- | --- |
| S3 | Clases de almacenamiento y reglas de vida |
| EC2 | Tipos y modelos de pago |
| Lambda | Restricciones de ejecución |
| ECS | Control de contenedores |

> "La guía cubre recursos de documentación, soporte técnico y explica cómo AWS cobra por sus servicios" - AWS Certified Cloud Practitioner Study Guide

**Para prepararte:**

- Usa la consola de AWS
- Lee los límites de cada servicio
- Practica conectando servicios entre sí

El examen usa casos prácticos. Entre más practiques en la consola real, mejor preparado estarás.

## 3. Guía de Seguridad AWS {id="3.-gu%C3%ADa-de-seguridad-aws"}

AWS divide la seguridad en dos partes: ellos protegen la infraestructura, tú proteges tus datos.

| AWS Se Encarga De | Tú Te Encargas De |
| --- | --- |
| Seguridad física | Datos de usuarios |
| Hardware | Configuración de servicios |
| Redes | Permisos IAM |
| Software base | Cifrado |

**4 Temas de Seguridad que SIEMPRE Preguntan:**

| Tema | Servicios | Lo Básico |
| --- | --- | --- |
| Identidad | IAM, MFA | Quién puede hacer qué |
| Redes | VPC, Security Groups | Control del tráfico |
| Datos | KMS, SSL/TLS | Protección de información |
| Monitoreo | CloudTrail, CloudWatch | Ver qué pasa |

**Así Lo Hace [Capital One](https://en.wikipedia.org/wiki/Capital_One):**

- MFA para TODOS
- Solo los permisos necesarios
- CloudTrail para ver todo
- Datos importantes = datos cifrados

**En El Examen Van a Preguntar:**

1\. **Quién Hace Qué**

AWS y tú tienen trabajos diferentes. Debes saber cuáles son.

2\. **Herramientas de Seguridad**

Cada servicio tiene su momento y lugar. ¿Cuándo usar cada uno?

3\. **Lo Que SIEMPRE Debes Hacer**

- MFA en cuentas root
- Cifrar todo
- Guardar logs

**No Hagas Estos Errores:**

| Error | Problema | Qué Hacer |
| --- | --- | --- |
| Root sin MFA | Te pueden hackear | Pon MFA YA |
| Dar muchos permisos | Riesgo de fugas | Da lo mínimo |
| S3 abiertos | Datos expuestos | Revisa permisos |

> "La seguridad en AWS es como una cebolla: necesitas varias capas, empezando por proteger la cuenta root" - AWS Security Whitepaper

**Para Aprobar, Memoriza:**

- Qué hace AWS y qué haces tú
- Cómo configurar IAM
- Cómo cifrar en S3 y RDS
- Para qué sirve CloudTrail

## 4. Patrones de Diseño en la Nube {id="4.-patrones-de-dise%C3%B1o-en-la-nube"}

Los patrones de diseño en AWS son las bases para construir en la nube. Veamos cómo funcionan.

| Patrón | Uso | [Servicios AWS](/blog/aws-aprender-guia-inicial/) |
| --- | --- | --- |
| Microservicios | Apps modulares | ECR, ECS, Fargate |
| Anti-corrupción | Sistemas híbridos | API Gateway, Lambda |
| Publicar-Suscribir | Mensajería | SNS, SQS |
| Saga | Control distribuido | Step Functions |
| Outbox | Datos consistentes | DynamoDB, Lambda |

**Lo Básico Para el Examen:**

| Componente | Qué Hace | Por Qué |
| --- | --- | --- |
| Contenedores | ECR guarda, ECS ejecuta | Base de apps modernas |
| Sin servidor | Lambda + API Gateway | Menos trabajo |
| Bases de datos | Cada servicio, su base | Mejor desempeño |
| Monitoreo | CloudWatch + X-Ray | Control total |

**En la Práctica:**

1\. **Apps en Contenedores**

ECR guarda tus imágenes. ECS Fargate las ejecuta. CloudWatch te dice cómo van.

2\. **Control de Fallos**

CloudFront maneja errores. Route 53 dirige el tráfico. API Gateway controla tiempos.

3\. **Webhooks Automáticos**

Lambda procesa. DynamoDB guarda. CloudWatch supervisa.

**Datos Clave:**

| Qué Mide | Resultado | Origen |
| --- | --- | --- |
| Eficiencia | 60% más | [CloudKitect Patterns](https://cloudkitect.com/cloudkitect-patterns/) |
| Costos | -80% | CloudKitect Patterns |
| Despliegue | 1 hora | CloudKitect Patterns |

**Para Aprobar:**

- Domina ECR, ECS y Lambda
- Conoce cada patrón y cuándo usarlo
- Haz pruebas reales
- Entiende cómo se conecta todo

> "CloudKitect optimiza según el ambiente: desarrollo, pruebas o producción. Así ahorras sin sacrificar calidad" - CloudKitect Patterns

## Guía de Almacenamiento AWS {id="gu%C3%ADa-de-almacenamiento-aws"}

AWS tiene 3 opciones de almacenamiento. Veamos para qué sirve cada una:

| Tipo | Servicio | Perfecto Para | Durabilidad |
| --- | --- | --- | --- |
| Objetos | S3 | Webs, apps | 99.999999999% |
| Archivos | EFS | Apps compartidas | 99.999999999% |
| Bloques | EBS | Bases de datos | 99.8% - 99.999% |

**S3: Las Clases que Necesitas Conocer**

| Clase | ¿Cuándo Usarla? | Disponibilidad | Tiempo Mínimo |
| --- | --- | --- | --- |
| Standard | Datos de uso diario | 99.99% | No hay |
| Standard-IA | Datos poco frecuentes | 99.9% | 30 días |
| One Zone-IA | Datos que puedes recrear | 99.5% | 30 días |
| Glacier | Backups y archivos | 99.9% | 90 días |

**EBS: Opciones de Volumen**

| Tipo | IOPS Máx | MB/s Máx | Capacidad |
| --- | --- | --- | --- |
| io2 | 64,000 | 1,000 | 4GB-16TB |
| gp2 | 16,000 | 250 | 1GB-16TB |
| st1 | 500 | 500 | 125GB-16TB |

**Lo Básico para el Examen:**

S3 es para datos sin estructura - como fotos o videos. Accedes por API y es PERFECTO para webs.

EFS es tu sistema de archivos en red. Múltiples EC2 pueden usarlo a la vez. Ideal para apps empresariales.

EBS es como el disco duro de tu EC2. Respuesta rápida y EXCELENTE para bases de datos.

**Números que Importan:**

| Servicio | Durabilidad | Uso Principal |
| --- | --- | --- |
| S3 | 11 9s | Web y contenido |
| EFS | 11 9s | Apps compartidas |
| EBS | 5 9s | Bases de datos |

**¿Cuánto Cuesta?**

| Servicio | Pagas Por | Extras |
| --- | --- | --- |
| S3 | GB almacenado | Transferencia |
| EFS | GB usado | Acceso |
| EBS | GB reservado | IOPS |

**Para Aprobar el Examen:**

- Aprende los 3 tipos de almacenamiento
- Memoriza las clases de S3
- Identifica cuándo usar cada servicio
- Conoce las diferencias de durabilidad

## FAQs {id="faqs"}

### ¿Cuáles son los 5 pilares de AWS? {id="%C2%BFcu%C3%A1les-son-los-5-pilares-de-aws%3F"}

Los pilares de AWS son la base del AWS Well-Architected Framework. Este marco te ayuda a construir sistemas en la nube que funcionen.

Aquí están los pilares:

| Pilar | Función Principal |
| --- | --- |
| Excelencia Operativa | Ejecutar y monitorear sistemas |
| Seguridad | Proteger datos y sistemas |
| Fiabilidad | Mantener sistemas funcionando |
| Eficiencia del Rendimiento | Usar recursos de manera efectiva |
| Optimización de Costos | Gastar lo necesario |
| Sostenibilidad | Reducir impacto ambiental |

Para el examen, necesitas saber esto:

Las preguntas suelen presentar situaciones donde tendrás que identificar qué pilar aplica. No es raro ver preguntas que mezclan varios pilares a la vez.

| Pilar | % Preguntas en Examen |
| --- | --- |
| Seguridad | 25-30% |
| Costos | 20-25% |
| Rendimiento | 15-20% |
| Fiabilidad | 15-20% |
| Operaciones | 10-15% |

El AWS Well-Architected Framework es un documento clave para tu examen. Léelo con atención - aparece MUCHO en las preguntas.
