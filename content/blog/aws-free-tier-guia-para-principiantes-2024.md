El [AWS](https://aws.amazon.com/) Free Tier es un programa gratuito de Amazon Web Services que te permite explorar y probar una amplia variedad de servicios en la nube sin costo alguno. Ofrece tres tipos de ofertas:

| Tipo de oferta | Descripción |
| --- | --- |
| 12 meses gratis | Acceso gratuito a ciertos servicios durante 12 meses |
| Siempre gratis | Acceso gratuito permanente a ciertos servicios |
| Pruebas gratuitas a corto plazo | Acceso gratuito a ciertos servicios por un período limitado |

El programa cubre más de 100 productos y servicios de AWS, incluyendo computación, almacenamiento, bases de datos, seguridad, análisis y aprendizaje automático. Es ideal para principiantes, emprendedores y pequeñas empresas que deseen familiarizarse con la nube de AWS sin compromiso financiero.

Para evitar cargos adicionales, es crucial monitorear tu uso y mantenerte dentro de los límites establecidos. AWS proporciona herramientas como [AWS Budgets](https://aws.amazon.com/aws-cost-management/aws-budgets/) y la API GetFreeTierUsage para rastrear tu consumo.

En resumen, el AWS Free Tier es una excelente oportunidad para aprender y experimentar con los servicios en la nube de AWS de forma gratuita. Aprovecha al máximo esta oferta siguiendo las mejores prácticas y manteniendo un control sobre tu uso.

## Iniciar con AWS Free Tier {id="iniciar-con-aws-free-tier"}

### Crear una cuenta de AWS {id="crear-una-cuenta-de-aws"}

Para empezar a utilizar el AWS Free Tier, debes crear una cuenta de AWS. Este proceso es rápido y sencillo. Sigue estos pasos:

1. **Visita la página de registro de AWS**: Abre un navegador y ve a la página de registro de AWS en <https://portal.aws.amazon.com/billing/signup#/start/email>.
2. **Ingresa tu dirección de correo electrónico y contraseña**: Ingresa una dirección de correo electrónico válida y crea una contraseña segura para tu cuenta de AWS.
3. **Selecciona el tipo de cuenta**: Selecciona si deseas crear una cuenta personal o profesional. Si eres un desarrollador individual, selecciona "Personal". Si eres una empresa o una organización, selecciona "Profesional".
4. **Ingresa tus datos personales**: Ingresa tus datos personales, como tu nombre y apellido, dirección y número de teléfono.
5. **Verifica tu cuenta**: AWS te enviará un correo electrónico para verificar tu cuenta. Haz clic en el enlace de verificación para activar tu cuenta.

### Uso de la consola de AWS {id="uso-de-la-consola-de-aws"}

Una vez que hayas creado tu cuenta de AWS, puedes acceder a la consola de AWS. La consola de AWS es una interfaz gráfica de usuario que te permite administrar tus recursos de AWS de manera sencilla y eficiente. Sigue estos pasos para empezar a utilizar la consola de AWS:

| Paso | Descripción |
| --- | --- |
| 1 | **Inicia sesión en la consola de AWS**: Ve a la página de inicio de sesión de AWS en <https://console.aws.amazon.com> e ingresa tus credenciales de acceso. |
| 2 | **Selecciona la región adecuada**: Selecciona la región geográfica donde deseas crear tus recursos de AWS. |
| 3 | **Explora los servicios de AWS**: La consola de AWS te muestra una lista de servicios de AWS disponibles. Explora los servicios que te interesan y haz clic en ellos para obtener más información. |
| 4 | **Crea un recurso de AWS**: Sigue las instrucciones para crear un recurso de AWS, como una instancia de Amazon EC2 o un bucket de Amazon S3. |

Recuerda que la consola de AWS es una herramienta poderosa que te permite administrar tus recursos de AWS de manera eficiente. Asegúrate de leer la documentación de AWS para obtener más información sobre cómo utilizar la consola de AWS.

## Facturación y costos del AWS Free Tier {id="facturaci%C3%B3n-y-costos-del-aws-free-tier"}

La forma en que se factura y cobra el uso del AWS Free Tier es fundamental para entender cómo aprovechar al máximo este programa. En esta sección, exploraremos cómo funciona la facturación del AWS Free Tier, cómo rastrear el uso contra los límites del Free Tier y qué sucede cuando se agota el período de Free Tier.

### Rastrear el uso del Free Tier {id="rastrear-el-uso-del-free-tier"}

Para evitar sorpresas en la facturación, es importante rastrear el uso del AWS Free Tier contra los límites establecidos. AWS ofrece varias formas de hacerlo:

| Método | Descripción |
| --- | --- |
| **EC2 Free Tier box** | En la pantalla de inicio de la consola de AWS, en la esquina superior derecha, hay una caja que muestra el uso actual del Free Tier de EC2. |
| **GetFreeTierUsage API** | La API GetFreeTierUsage permite obtener información detallada sobre el uso del Free Tier en su cuenta. |
| **AWS Budgets** | AWS Budgets es una herramienta que le permite establecer límites de gasto y recibir alertas cuando se acerca a esos límites. |

### Después de que finaliza el período de Free Tier {id="despu%C3%A9s-de-que-finaliza-el-per%C3%ADodo-de-free-tier"}

Cuando se agota el período de Free Tier, es importante tomar medidas para evitar sorpresas en la facturación. Aquí hay algunas sugerencias:

- **Configurar AWS Budgets**: Configure AWS Budgets para recibir alertas cuando se acerca al límite de gasto.
- **Optimizar el uso de recursos**: Asegúrese de que esté utilizando los recursos de AWS de manera eficiente.
- **Actualizar a una cuenta de pago**: Si su uso del AWS Free Tier ha superado los límites, puede actualizar a una cuenta de pago para continuar utilizando los servicios de AWS.

Recuerde que es importante entender cómo funciona la facturación del AWS Free Tier para aprovechar al máximo este programa y evitar sorpresas en la facturación.

## Preguntas frecuentes {id="preguntas-frecuentes"}

### ¿Qué obtengo con una cuenta de AWS free tier? {id="%C2%BFqu%C3%A9-obtengo-con-una-cuenta-de-aws-free-tier%3F"}

Obtienes la capacidad de explorar y probar los servicios de AWS sin cargo hasta límites específicos para cada servicio. La capa gratuita se compone de tres tipos de ofertas diferentes: 12 meses gratis, siempre gratis y pruebas gratuitas a corto plazo.

### ¿Qué sucede después de 12 meses de AWS free tier? {id="%C2%BFqu%C3%A9-sucede-despu%C3%A9s-de-12-meses-de-aws-free-tier%3F"}

Cuando tu término de uso gratuito de 12 meses expire, o si el uso de tu aplicación excede los límites, simplemente pagas las tarifas estándar de pago por uso para cada servicio. Las ofertas siempre gratuitas no expiran y están disponibles para todos los clientes de AWS.

### ¿Cuál es la diferencia entre AWS free tier profesional y personal? {id="%C2%BFcu%C3%A1l-es-la-diferencia-entre-aws-free-tier-profesional-y-personal%3F"}

La cuenta profesional es para empresas o uso empresarial, mientras que la cuenta personal es para aprender y experimentar con los servicios de AWS.

### ¿Es AWS free tier gratuito de por vida? {id="%C2%BFes-aws-free-tier-gratuito-de-por-vida%3F"}

No, la capa gratuita de AWS se aplica a tu uso mensual. Expira el primer día de cada mes y no se acumula.
