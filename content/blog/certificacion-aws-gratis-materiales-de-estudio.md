Seguramente todos estarán de acuerdo en que **prepararse para una certificación AWS puede ser costoso y difícil sin los recursos adecuados**.

Afortunadamente, AWS ofrece muchos **materiales de estudio gratuitos** para ayudarte a prepararte para sus certificaciones sin gastar dinero.

En este artículo, exploraremos los **recursos gratuitos que AWS pone a tu disposición**, como AWS Skill Builder, documentación técnica, whitepapers, laboratorios prácticos y más. También veremos una guía paso a paso sobre cómo prepararte para la certificación AWS Cloud Practitioner aprovechando estos recursos gratuitos de AWS.

## Introducción a la Certificación AWS Gratuita {id="introducci%C3%B3n-a-la-certificaci%C3%B3n-aws-gratuita"}

En esta introducción se presenta el tema de la [certificación AWS gratuita](https://www.wetcom.com/en_US/blog/blog-1/como-preparar-la-certificacion-aws-cloud-practitioner-608) y se describe brevemente el contenido que se cubrirá en el artículo.

### Comprendiendo la importancia de la certificación AWS gratis {id="comprendiendo-la-importancia-de-la-certificaci%C3%B3n-aws-gratis"}

Las [certificaciones de AWS](https://www.youtube.com/watch?v=XR4yIrSpywc) son credenciales emitidas por Amazon Web Services que validan los conocimientos y habilidades en sus tecnologías y servicios en la nube. Obtener estas certificaciones es importante por varias razones:

- Demuestra experticia en servicios de AWS como EC2, S3, Lambda, etc. Esto mejora el perfil profesional.
- Permite acceder a mejores oportunidades laborales y salarios más altos. Las empresas buscan talento certificado en AWS.
- Prepara para roles como desarrollador, arquitecto o administrador en la nube.
- Valida ante empleadores y colegas las habilidades técnicas en AWS.

AWS ofrece varios **recursos gratuitos** para prepararse para sus certificaciones:

- **AWS Skill Builder:** plataforma de aprendizaje en línea con cursos, laboratorios y exámenes de práctica.
- **AWS Training and Certification:** incluye materiales de estudio como presentaciones, libros blancos y guías de examen.
- **AWS Certified Cloud Practitioner:** curso y examen de certificación gratis durante 12 meses para nuevos usuarios de AWS.

### Perfil del candidato para la certificación AWS {id="perfil-del-candidato-para-la-certificaci%C3%B3n-aws"}

El perfil típico del candidato para obtener una certificación de AWS es:

- Profesionales de TI hispanohablantes como desarrolladores, ingenieros DevOps, administradores de sistemas y arquitectos en la nube.
- Personas con conocimientos básicos o intermedios buscando validar o mejorar sus habilidades.
- Empleados que necesitan una certificación AWS para su trabajo actual o futuro.
- Estudiantes de carreras de TI que quieren mejorar su currículum y oportunidades laborales.

La certificación ayuda a estos perfiles a mejorar sus habilidades en la nube, conseguir mejores trabajos y salarios y avanzar en sus carreras profesionales.

## ¿Cuánto cuesta una certificación de AWS? {id="%C2%BFcu%C3%A1nto-cuesta-una-certificaci%C3%B3n-de-aws%3F"}

La mayoría de las certificaciones de AWS tienen un costo de examen de 100 USD. Sin embargo, AWS ofrece algunos recursos gratuitos para ayudarte a prepararte para los exámenes sin tener que pagar por cursos de capacitación costosos.

### Materiales de estudio gratuitos {id="materiales-de-estudio-gratuitos"}

AWS pone a disposición guías de estudio, videos, ejercicios prácticos y exámenes de práctica gratuitos a través de su plataforma [AWS Skill Builder](https://www.aws.training/LearningLibrary). Puedes acceder a todos estos recursos sin costo alguno simplemente creando una cuenta de AWS.

Adicionalmente, AWS ofrece un [curso gratuito de Conceptos Técnicos Básicos de AWS](https://www.aws.training/Details/Curriculum?id=27076) que cubre los fundamentos que necesitas saber antes de obtener la certificación Foundational. Este curso está disponible en español y no tiene ningún costo.

### Exámenes de práctica gratuitos {id="ex%C3%A1menes-de-pr%C3%A1ctica-gratuitos"}

AWS también proporciona a todos sus usuarios exámenes de práctica gratuitos que puedes realizar tantas veces como quieras. Estos exámenes simulan muy bien las condiciones reales del examen de certificación y te permiten probar tus conocimientos para identificar áreas de mejora.

En conclusión, si bien los exámenes de [certificación de AWS](https://podcast.marcia.dev/) tienen un costo, la preparación puede realizarse de forma gratuita a través de los abundantes recursos que AWS pone a disposición en su plataforma de capacitación en línea.

## ¿Dónde aprender AWS gratis? {id="%C2%BFd%C3%B3nde-aprender-aws-gratis%3F"}

Los mejores cursos en línea gratis sobre Amazon Web Services (AWS), los puedes encontrar en la plataforma de edX.

### AWS Skill Builder {id="aws-skill-builder"}

AWS Skill Builder ofrece una amplia variedad de cursos gratuitos para aprender sobre los servicios de AWS. Algunos cursos populares son:

- AWS Technical Essentials
- Data Analytics Fundamentals
- AWS Compute Services Overview

Estos cursos son ideales para principiantes que buscan obtener una comprensión básica de los servicios de AWS. No requieren conocimientos previos y presentan los conceptos de una manera fácil de entender.

Además, AWS Skill Builder tiene "Learning Paths" o planes de aprendizaje que agrupan varios cursos relacionados para guiarte paso a paso en un área específica. Por ejemplo, el plan "Cloud Essentials Learning Plan" cubre conceptos esenciales sobre la nube de AWS.

### Certificaciones AWS gratuitas {id="certificaciones-aws-gratuitas"}

Otra opción es prepararse para una de las certificaciones de AWS. AWS ofrece un nivel gratuito de sus certificaciones más populares, como:

- AWS Certified Cloud Practitioner
- AWS Certified Developer - Associate
- AWS Certified Solutions Architect - Associate

El nivel gratuito te permite realizar el examen de certificación sin costo. Es una buena manera de validar tus conocimientos técnicos sobre los servicios de AWS.

Además, AWS provee guías de estudio y recursos gratuitos para prepararte para estos exámenes, como videos, libros electrónicos y exámenes de práctica. Consulta la página web de cada certificación para acceder a estos valiosos materiales de estudio.

En resumen, AWS Skill Builder y las certificaciones gratuitas son excelentes opciones para aprender AWS sin costo alguno. ¡Aprovéchalos!

## ¿Cómo obtener el certificado AWS? {id="%C2%BFc%C3%B3mo-obtener-el-certificado-aws%3F"}

Para obtener una certificación de AWS es necesario aprobar un examen cronometrado y supervisado. Existen dos formas principales de rendir estos exámenes:

### En persona {id="en-persona"}

Puedes presentarte en cualquier centro autorizado de Pearson VUE para rendir el examen de certificación AWS. Cuando reserves tu examen, asegúrate de seleccionar un centro cercano a tu ubicación. El día del examen deberás presentar una identificación válida con foto.

Los exámenes en persona tienen un costo que va desde los $100 hasta los $300 dólares aproximadamente, dependiendo del tipo de certificación.

### En línea {id="en-l%C3%ADnea"}

También puedes rendir los exámenes de certificación AWS desde la comodidad de tu casa u oficina a través de Pearson OnVUE, la plataforma de exámenes en línea. Sólo necesitas una computadora, webcam y conexión a internet estable.

Al igual que en persona, deberás presentar una identificación válida antes de comenzar el examen. Los precios son similares a los exámenes presenciales.

Independientemente de la modalidad que elijas, es importante prepararse a conciencia [estudiando los servicios y características de AWS](https://open.spotify.com/show/2rCidXkaGixk0OFFJ7ol7b?si=c8031828ebfe44c8), así como realizando exámenes de práctica. AWS ofrece varios recursos gratuitos, como guías de estudio y laboratorios prácticos, que puedes aprovechar en tu preparación para obtener la certificación.

## ¿Qué es gratis en AWS? {id="%C2%BFqu%C3%A9-es-gratis-en-aws%3F"}

AWS ofrece varios servicios y recursos gratuitos para que puedas probar y aprender sobre la nube sin costo. Esto incluye:

### 12 meses gratis {id="12-meses-gratis"}

Al crear una cuenta nueva de AWS, obtienes acceso gratuito por 12 meses a más de 60 servicios, incluyendo un uso mensual de:

- EC2 - 750 horas de instancias t2.micro
- S3 - 5GB de almacenamiento estándar
- RDS - 750 horas de base de datos db.t2.micro

Esto te permite probar una amplia gama de servicios por un año sin costo mientras aprendes.

### Siempre gratis {id="siempre-gratis"}

AWS también ofrece un nivel "Siempre gratis" que no caduca. Algunos de los servicios incluidos son:

- Lambda - 1 millón de solicitudes gratis al mes
- DynamoDB - 25GB de almacenamiento gratis al mes
- SNS - 1 millón de solicitudes gratis al mes

Puedes usar estos servicios de forma gratuita de por vida mientras estés dentro de los límites.

### Pruebas gratuitas a corto plazo {id="pruebas-gratuitas-a-corto-plazo"}

Finalmente, AWS permite probar muchos servicios de forma gratuita por un tiempo limitado, normalmente entre 30-60 días. Por ejemplo, puedes acceder a una instancia gratuita de Amazon Redshift durante 60 días.

En resumen, AWS te da muchas oportunidades para aprender y experimentar con la nube sin costo. Aprovecha todas estas ofertas gratuitas mientras te preparas para las certificaciones.

## Explorando las Certificaciones AWS {id="explorando-las-certificaciones-aws"}

AWS ofrece una amplia gama de certificaciones para validar los conocimientos y habilidades en la nube. Estas certificaciones están organizadas en 3 niveles principales:

### Niveles y categorías de las certificaciones AWS {id="niveles-y-categor%C3%ADas-de-las-certificaciones-aws"}

Las certificaciones de AWS se dividen en 3 niveles:

- **Foundational**: Son certificaciones de nivel básico, ideales para personas que recién comienzan con la nube de AWS. No requieren experiencia previa. Algunos ejemplos son AWS Certified Cloud Practitioner y AWS Certified Data Analytics Specialty.
- **Associate**: Son certificaciones de nivel intermedio, diseñadas para personas con al menos 1 año de experiencia usando AWS en una variedad de funciones como desarrolladores, administradores de sistemas y arquitectos de soluciones. Algunos ejemplos populares son AWS Certified Solutions Architect – Associate y AWS Certified Developer – Associate.
- **Professional**: Son certificaciones avanzadas que validan habilidades especializadas en roles específicos. Requieren al menos 2 años de experiencia en posiciones de liderazgo o roles técnicos complejos. Un ejemplo es AWS Certified Solutions Architect – Professional.

### Certificaciones AWS populares y especializadas {id="certificaciones-aws-populares-y-especializadas"}

Algunas de las certificaciones AWS más populares son:

- **AWS Certified Solutions Architect**: Valida habilidades para diseñar sistemas escalables y de alto rendimiento en AWS. Existen 2 niveles: Associate y Professional.
- **AWS Certified Developer**: Valida habilidades de programación para crear y desplegar aplicaciones seguras y escalables en AWS.
- **AWS Certified SysOps Administrator**: Valida habilidades para administrar aplicaciones en AWS enfocándose en mejorar disponibilidad, confiabilidad y eficiencia operacional.

AWS también ofrece certificaciones especializadas enfocadas en servicios específicos como bases de datos, analytics, machine learning y seguridad. Algunos ejemplos son AWS Certified Database Specialty y AWS Certified Security Specialty.

### Directorio completo de certificaciones AWS {id="directorio-completo-de-certificaciones-aws"}

AWS cuenta actualmente con las siguientes certificaciones:

- **Nivel Foundational**: AWS Certified Cloud Practitioner, AWS Certified Data Analytics Specialty, AWS Certified Machine Learning Specialty.
- **Nivel Associate**: AWS Certified Solutions Architect – Associate, AWS Certified Developer – Associate, AWS Certified SysOps Administrator – Associate.
- **Nivel Professional**: AWS Certified Solutions Architect – Professional, AWS Certified DevOps Engineer – Professional.
- **Especializaciones**: AWS Certified Security – Specialty, AWS Certified Advanced Networking – Specialty, AWS Certified Database – Specialty, AWS Certified Alexa Skill Builder – Specialty.

Cada certificación valida un conjunto específico de habilidades técnicas y de la nube. Es importante elegir la certificación que mejor se alinee con tus objetivos profesionales.

## Guía para Obtener la Certificación AWS Cloud Practitioner Gratis {id="gu%C3%ADa-para-obtener-la-certificaci%C3%B3n-aws-cloud-practitioner-gratis"}

Se explica el proceso general para obtener una certificación de AWS de forma gratuita.

### Selección de la Certificación AWS adecuada {id="selecci%C3%B3n-de-la-certificaci%C3%B3n-aws-adecuada"}

La certificación AWS Cloud Practitioner es ideal para comenzar en el mundo de AWS y la computación en la nube. No requiere conocimientos técnicos previos y presenta los conceptos y servicios de AWS a un alto nivel.

Otras certificaciones como AWS Certified Solutions Architect o AWS Certified Developer son más avanzadas y enfocadas a roles específicos. Requieren mayor experiencia en la plataforma.

Es recomendable comenzar con la certificación Cloud Practitioner para luego avanzar a certificaciones más especializadas según el área de interés.

### Registro y acceso a la capa gratuita de AWS {id="registro-y-acceso-a-la-capa-gratuita-de-aws"}

Para acceder a los recursos de aprendizaje gratuitos de AWS es necesario crear una cuenta en AWS. El registro es gratuito y permite activar la capa gratuita de AWS (AWS Free Tier).

La capa gratuita da acceso por 12 meses a servicios de AWS esenciales para aprendizaje, como EC2, S3, RDS, etc. También permite rendir el examen de certificación Cloud Practitioner sin costo.

Es importante activar la capa gratuita durante el registro para poder aprovechar estos beneficios.

### Preparación con recursos de AWS Skill Builder {id="preparaci%C3%B3n-con-recursos-de-aws-skill-builder"}

AWS Skill Builder es la plataforma de aprendizaje de AWS. Cuenta con cursos, laboratorios prácticos, videos y otros contenidos para prepararse para las certificaciones.

Muchos de los recursos son gratuitos, como el curso AWS Technical Essentials y el examen de práctica para la certificación Cloud Practitioner. Estos son esenciales para prepararse para el examen real.

También existen recursos más avanzados como los cursos de Associate y Professional que tienen costo. Pero los contenidos gratuitos son suficientes para la certificación inicial de Cloud Practitioner.

### Estrategias de estudio para AWS Certified Cloud Practitioner {id="estrategias-de-estudio-para-aws-certified-cloud-practitioner"}

Una vez completados los cursos en Skill Builder, es momento de programar el examen en un centro de testing autorizado por AWS.

La certificación Cloud Practitioner no tiene prerequisitos ni experiencia previa necesaria. El examen consta de 65 preguntas de opción múltiple y su duración es de 90 minutos.

Algunas estrategias útiles para rendir el examen son: leer bien cada pregunta, descartar respuestas incorrectas, no dejar preguntas sin responder y administrar bien el tiempo.

La preparación adecuada y buenas estrategias de examen son claves para obtener la certificación AWS Cloud Practitioner de forma gratuita, como primer paso en el mundo de la nube de AWS.
